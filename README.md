# 📝 SimonPad – Ultimate Text Editor

**Author:** 12 years old kid 💻  
**Description:** SimonPad is an ultra-cool text editor with **syntax highlighting** for Python, C, and C++. You can change fonts, colors, and even set a background image.  
Now it’s a **standalone exe** – no Python needed, just double-click and code!

---

## 🚀 Run the Executable
Double-click `SimonPad.exe` and start coding.  
Everything works out-of-the-box, no extra installs required.

---

## ⚡ Features
- Syntax highlighting: Python / C / C++  
- Transparent editor with **background image support**  
- Change font size, font family, and colors  
- New file / Open / Save functionality  
- Status bar with line count, language, and time  
- Undo / Redo  
- Modern GUI made with **CustomTkinter**

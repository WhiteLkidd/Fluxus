# FShell

**FShell** is the official shell for the **Fluxus programming language**.  
It provides an interactive environment similar to **Python REPL, JShell or Node.js console**.

FShell allows you to run Fluxus code line by line without creating a file.

Created by **Simon (Lord Simon)**.

---

# Features

- Interactive Fluxus REPL
- Execute code line-by-line
- Fast testing of Fluxus functions
- Error handling without crashing the shell
- Simple command system
- Lightweight C implementation
